# Snake Queue

A to-do list where every task is a piece of a snake. The more you have to do, the longer it gets; the piece touching the head is next.

Live at [jotaverse.com.br/snake-queue](https://jotaverse.com.br/snake-queue/).

- **add**: type and press Enter (`/` focuses the field)
- **read**: hover or focus a piece, the task shows under the board; arrow keys walk the queue
- **finish**: click a piece, or Enter on it; `Del` finishes the first; `Ctrl+Z` undoes
- **edit**: double click, or `E` on a piece
